# 마이파크(MYPARK) 스크린 파크골프 상권 & 사업분석 자동화 솔루션

공공데이터(KOSIS 인구통계, 소상공인365 상권데이터)와 정밀 재무 모델링(3대 시나리오 5개년 손익/BEP)을 결합하여, 고객에게 특정 입지가 스크린 파크골프에 최적인 이유를 설득력 있게 제시하는 자동화 보고서 제작 시스템입니다.

## 🚀 주요 기능
- **입지 최적성 5대 다이아몬드 지표 스코어링** (100점 만점)
- **KOSIS 기반 배후 인구 및 50~80대 시니어/여성 인구 자동 집계**
- **소상공인 365 12개월 매출 추이 및 요일/시간대/연령별 패턴 분석**
- **3대 시나리오(보수/보편/긍정) 월별/연간 손익 및 5개년 장기 전망**
- **손익분기점(BEP 회전율) 및 초기 투자금 회수 기간(Payback Period) 산출**
- **16:9 와이드 전문 프레젠테이션 PPTX(12장) & DOCX 출점타당성보고서 원클릭 다운로드**

## 🌐 Vercel 배포
본 프로젝트는 Vercel Serverless Python Function 및 정적 웹 대시보드로 배포되어 전 세계 어디서나 웹 브라우저로 접속해 사용할 수 있습니다.
